# Безопасность и публикация

Перед каждым публичным релизом выполните поиск секретов:

```powershell
rg -n "PrivateKey|PresharedKey|option key|password|shadow" .
```

Допустимы только заглушки `REPLACE_WITH_...` и TEST-NET endpoint `203.0.113.0/24`.

Никогда не включайте реальные VPN-конфиги, `/etc/config/network`, `/etc/config/wireless`, `/etc/shadow`, backup `sysupgrade -b`, SSH-пароль или журналы с ключами.

Официальный firmware и OpenWrt APK сверяйте с SHA-256 сервера OpenWrt. AmneziaWG APK получены из сторонней сборки `Slava-Shchipunov/awg-openwrt`; указывайте источник, tag и хеши. `--allow-untrusted` применяется только к заранее проверенному локальному набору без APK-индекса.

Однажды опубликованный приватный ключ следует считать скомпрометированным и заменить на клиенте и сервере.

Синтетические примеры могут содержать только `REPLACE_WITH_...` и адреса из
документационных диапазонов RFC 5737, например `203.0.113.10`. Перед commit запустите
`tools/validate-repo.ps1`; при наличии `gitleaks` дополнительно выполните:

```powershell
gitleaks detect --no-banner --redact
```

Не передавайте VPN-конфиг скрипту через аргумент командной строки как текст: путь к
закрытому файлу в `/tmp` безопаснее и не попадает в shell history. После успешного
импорта удалите временные конфиги и очистите их с компьютера публикации.
